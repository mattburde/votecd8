Tasks live in tasks.json in mattburde/votecd8 so this dashboard shows the same data on every device. Reading works with no setup. To save changes back to the repo from here, add a GitHub personal access token — fine-grained, scoped only to this repository, with Contents: Read and write permission. It's stored only in this browser's local storage and is sent only to api.github.com to commit tasks.json; it's never written into the page or the repo.

Without a token, edits are kept in this browser only (and marked unsynced) until you add one.
